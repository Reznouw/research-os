# Perspectivas de investigadores

Esta carpeta es para guardar transcripciones, notas o textos crudos de personas explicando como leen papers, escriben articulos, investigan, publican, revisan literatura o responden revisores.

No necesitas ordenar ni analizar el contenido. Puedes pegar lo que dice cada persona tal como lo tengas. Luego el sistema extraera patrones, consejos utiles, riesgos y reglas para nuestro flujo de investigacion.

## Que puedes guardar aqui

- Transcripciones de YouTube.
- Notas copiadas de videos.
- Blogs o posts largos.
- Hilos de redes sociales.
- Consejos de profesores, tesistas o investigadores.
- Experiencias personales sobre publicar papers.

## Nombre recomendado de archivos

Usa nombres simples:

```text
persona_o_canal_tema.txt
```

Ejemplos:

```text
profesor_x_como_leer_papers.txt
phd_y_como_escribir_introduccion.txt
investigador_z_como_publicar_ieee.txt
youtube_revision_literatura_tips.txt
```

## Formato recomendado dentro del archivo

Si puedes, empieza cada archivo con estos datos. Si no los tienes, no pasa nada.

```text
Titulo o tema:
Persona/canal:
URL:
Fecha de consulta:
Idioma:
Notas:

Transcripcion o contenido:
...
```

## Como lo procesara el sistema

Por cada archivo, se extraera:

- Consejo practico.
- Etapa donde aplica: lectura, busqueda, escritura, revision, publicacion.
- Nivel de confianza: experiencia personal, consenso repetido, evidencia metodologica.
- Riesgo: consejo general, sesgo de disciplina, posible mala practica.
- Adaptacion a nuestro sistema WBAN.
- Regla accionable para OpenCode.

## Importante

- No hace falta que el texto sea perfecto.
- No hace falta que separes consejos buenos y malos.
- No hace falta que me digas que parte sirve.
- Guarda el contenido crudo y luego el sistema se encargara de leer, comparar y extraer lo mejor.

## Salida esperada despues

Cuando haya varias perspectivas, se creara o actualizara:

```text
auditoria_investigacion/20_perspectivas_practicas_de_investigadores.md
```

Ese archivo convertira las transcripciones en reglas practicas para leer, pensar, escribir y publicar papers.
