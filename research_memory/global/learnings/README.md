# Aprendizajes globales del Research OS

Esta carpeta registra aprendizajes del sistema, no solo del paper WBAN. Cada aprendizaje debe poder reutilizarse en proyectos futuros: tesis, papers, revisiones de literatura, propuestas, defensas o entregables academicos.

## Regla

Cuando una sesion revele un error, confusion, mejora o patron repetible, convertirlo en una de estas salidas:

- regla de comportamiento;
- checklist;
- plantilla;
- actualizacion de skill;
- decision documentada;
- criterio de calidad.

## Formato sugerido

```text
Fecha:
Contexto:
Problema observado:
Por que importa:
Patron reutilizable:
Cambio recomendado:
Estado: propuesto | aplicado | descartado
```
