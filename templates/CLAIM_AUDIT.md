# Claim Audit

| Claim | Source | Locator | Evidence strength | Verdict | Required fix |
| --- | --- | --- | --- | --- | --- |
|  |  |  | direct / partial / weak / missing | SUPPORTED / PARTIAL / OVERSTATED / UNSUPPORTED / UNVERIFIED |  |

## Verdict Definitions

- `SUPPORTED`: source directly supports the claim.
- `PARTIAL`: source supports part of the claim or needs conditional wording.
- `OVERSTATED`: claim is stronger than the evidence.
- `UNSUPPORTED`: no sufficient source.
- `UNVERIFIED`: source, locator, table, formula, or method was not checked.
